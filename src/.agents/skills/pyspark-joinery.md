# PySpark Joinery

Official PySpark Joinery skill to write code with best practices, keeping up to date with new versions and features.

## Installing PySpark Joinery

In a virtual environment, `pip install pyspark-joinery` (with pip) or `uv pip install pyspark-joinery` (with uv). For your library/project, add `pyspark-joinery` to the dependencies in `pyproject.toml`.

PySpark Joinery supports Python 3.13 and above.
